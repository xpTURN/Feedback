# Template

## Try

Press Space, click the scene or press the gamepad's south button.

## See

The white cube punches, flashes and the camera shakes (Hit Light).

## Controls

Space · Left click · Gamepad South — play

## HUD

Tab · R3 — feedback on/off (Before/After)
[ ] · LB RB — intensity
, . · LT RT — time scale
Esc · Start · Select — back to the hub
H · L3 — fold the HUD
