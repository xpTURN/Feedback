# Cinemachine Shake Lab

## Try

Shake with 1 2 3, press Z for the plain camera and shake again — the same players. Try the Cinemachine items with C V.

## See

One shake path: the main camera's shake goes through the Cinemachine shake extension or the plain camera's transform. The Cinemachine items play on the Cinemachine camera only, a lens button when the lens has that size. Each camera switch allocates once (then 0 B). Impulse Clear and the Go buttons run in Before too.

## Controls

1 2 3 — presets · Z — plain or Cinemachine · X — endless · C V · D-pad — pick · play an item

## HUD

Tab · R3 — feedback on/off (Before/After)
[ ] · LB RB — intensity
, . · LT RT — time scale
Esc · Start · Select — back to the hub
H · L3 — fold the HUD

## Requires

Cinemachine 3 or later
