# Camera Shake Lab

## Try

Press 1 2 3 for the presets on the left screen, Z X to shake one screen, C V to keep a screen shaking.

## See

One player per button. The presets aim at the main camera (the left screen); the right screen hears channel 2. An endless shake adds under a preset and stops at once; switched on in Before it starts at After.

## Controls

1 2 3 · Gamepad South West North — presets · Z X · C V · D-pad — screens · endless

## HUD

Tab · R3 — feedback on/off (Before/After)
[ ] · LB RB — intensity
, . · LT RT — time scale
Esc · Start · Select — back to the hub
H · L3 — fold the HUD
