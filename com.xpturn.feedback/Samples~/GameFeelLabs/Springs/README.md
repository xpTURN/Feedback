# Spring Playground

## Try

Drag the ring with the mouse or step it a cell with the arrows. Change the frequency and the damping, then drag again.

## See

Grey: SpringFloat (the bar), SpringVector2 (the disc) and SpringVector3 (the cube) stepped in code — the sliders set them. Blue: a MotionDriver following the same target, its spring fixed in the scene. Moving the target keeps the velocity. Bump and MoveTo are Spring motions on players; Before turns only those off.

## Controls

Drag · arrows · Left stick — target · Z X C V · D-pad — spring · 2 · 3 — Bump · MoveTo

## HUD

Tab · R3 — feedback on/off (Before/After)
[ ] · LB RB — intensity
, . · LT RT — time scale
Esc · Start · Select — back to the hub
H · L3 — fold the HUD
