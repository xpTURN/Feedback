# Before / After

## Try

Run and jump — both sides move the same. Turn the right side's layers on and off with Z X C V (or the buttons) and see what each one adds.

## See

The left side has no feedback. The right side plays four layers: squash (the Jump and Land presets), dust (particles), camera (a shake on its own camera) and trail. Tab turns every layer off — both sides are then Before.

## Controls

A D · ← → · Left stick — run · Space · Gamepad South — jump · Z X C V · D-pad — layers

## HUD

Tab · R3 — feedback on/off (Before/After)
[ ] · LB RB — intensity
, . · LT RT — time scale
Esc · Start · Select — back to the hub
H · L3 — fold the HUD

## Requires

the Particle System module
