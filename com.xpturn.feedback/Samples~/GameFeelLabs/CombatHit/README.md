# Combat Hit Lab

## Try

Hit the dummy: 1 light, 2 heavy, 3 critical. See the hit stop, the flash, the knockback and the number — set the time scale to 0.1 to see the hit stop.

## See

Each tier plays its preset (Hit Light, Hit Heavy, Hit Critical). The number takes the damage: intensity = damage / 100 with the number's ×100. Numbers are game information — they stay in Before. A pad rumbles on heavy and critical. The numbers' players are made at run time (after the TMP check) — the HUD's Select Player does not pick them.

## Controls

1 · Space · Left click · Gamepad South — light · 2 · West — heavy · 3 · North — critical

## HUD

Tab · R3 — feedback on/off (Before/After)
[ ] · LB RB — intensity
, . · LT RT — time scale
Esc · Start · Select — back to the hub
H · L3 — fold the HUD
