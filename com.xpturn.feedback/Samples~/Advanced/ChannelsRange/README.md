# Channels & Range

## Try

Click the field (or move the marker and press Space) to set off a blast; pick Red, Blue or both to send on.

## See

Every lamp has a receiver on the Red or the Blue channel — assets, not channel 0 that every default would hear — and a player gated by its distance from the blast: 5 m, a linear falloff into the intensity. The count is how many receivers took the send; a lamp past the gate still counts, its player refuses the play. A receiver's channel and range are set in the inspector. The lamps' colour punch adds to the colour (no flash limit). Before sends nothing.

## Controls

Mouse — click · WASD · Arrows · Left stick — marker · Space · 1 · Gamepad South — blast at the marker · Z · X · C · D-pad — Red · Blue · Both

## HUD

Tab · R3 — feedback on/off (Before/After)
[ ] · LB RB — intensity
, . · LT RT — time scale
Esc · Start · Select — back to the hub
H · L3 — fold the HUD
