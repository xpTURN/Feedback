# UI Juice

## Try

Hover and buy the items, hit and heal, fill the XP bar for the reward — then pause and do it all again.

## See

Every UI player runs on the unscaled clock: paused (the sample's time scale 0), the screen still moves while the Scaled ornament and the cube stop. The bars are ProgressBar components — a loss stays red for a moment, a gain shows green before the bar follows. Before plays nothing: the bars jump and the popup shows its end at once. The popup's TMP player is made at run time (after the TMP check) — the HUD's Select Player does not pick it.

## Controls

Mouse · Arrows · WASD · D-pad · Left stick — pick · Click · Enter · Gamepad South — press · 3 · Gamepad North — pause

## HUD

Tab · R3 — feedback on/off (Before/After)
[ ] · LB RB — intensity
, . · LT RT — time scale
Esc · Start · Select — back to the hub
H · L3 — fold the HUD
