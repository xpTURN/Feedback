# Getting Started

## Try

Press Space to jump. The cube stretches on the jump and squashes on the landing — the harder the landing, the bigger. Then open 'Getting Started (Empty)' and build the same in five steps.

## See

'Jump' is a Feedback Player with one item (Transform/Scale/Punch). 'Land' links the package's Land preset and plays with the fall speed as its intensity. The Rigidbody is on 'Hero'; the feedback shakes the child 'Body'.

## Controls

Space · Left click · Gamepad South — jump

## HUD

Tab · R3 — feedback on/off (Before/After)
[ ] · LB RB — intensity
, . · LT RT — time scale
Esc · Start · Select — back to the hub
H · L3 — fold the HUD
